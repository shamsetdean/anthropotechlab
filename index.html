Méthode

Un seul fil conducteur.

ISobriété des données

Ne collecter que ce dont un projet ne peut pas se passer. La plupart des outils fonctionnent entièrement dans le navigateur. Quand un service doit partager des données, il le dit et les efface dès qu'il peut.

IIComprendre ce qu'on utilise

HTML, CSS, JavaScript, Python, Raspberry Pi. Peu de dépendances, chacune choisie en connaissance de cause.

IIIHébergement libre

GitHub Pages, un Raspberry Pi, et des offres gratuites quand un projet a besoin d'un serveur. Aucun coût imposé, aucune plateforme subie.

IVForme = message

Un site sur la maîtrise numérique doit être lui-même maîtrisé : celui-ci ne dépose aucun cookie et charge ses polices depuis son propre dossier.

Comment c'est fait

Des outils choisis, des raisons assumées.

APIs publiques

Des sources officielles, ouvertes et documentées, plutôt que des bases maison.

  • TMDB : Fabulae
  • IDFM / PRIM : Talaria
  • OpenStreetMap : Talaria, UFindGo
  • Open-Meteo : Talaria
GitHub Pages et Pi

Le statique, c'est-à-dire la majorité, sur GitHub Pages. Les automatisations sur un Raspberry Pi à la maison.

  • Aucun coût, code consultable
  • π.stream, scripts Python
Vercel

Pour les projets qui ont besoin d'un serveur : un déploiement en un envoi Git, sur l'offre gratuite.

  • Fabulae, Talaria, Synapse
  • Sources toujours sur Git
Supabase et Firebase

Quand un projet doit enregistrer ou partager des données, avec des règles d'accès strictes.

  • Supabase : Clavium, Fabulae, exceptōr, comptes DNDVDL-MAP
  • Firebase : signalements UFindGo, effacés en 24 h

Pourquoi le gratuit ? Tant qu'un outil reste gratuit, il reste accessible à quiconque veut bâtir : un étudiant, un autodidacte, une association. Quand un service devient payant, je migre.
