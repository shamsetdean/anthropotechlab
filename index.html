SECTION 06 / Stack & méthode

Comment c'est fait

Outils choisis Raisons assumées
APIs publiques DONNÉES

Plutôt que de scraper ou de bâtir mes propres bases, je m'appuie sur des APIs officielles, ouvertes et documentées. C'est plus rapide, plus fiable, et ça respecte le travail des organismes qui les maintiennent.

  • TMDB — base de données séries (Fabulae)
  • IDFM / PRIM — transports Île-de-France (Talaria)
  • OpenStreetMap — cartographie libre (Talaria, Vacuum)
  • Open-Meteo — météo sans clé (Talaria, iter)
Vercel HÉBERGEMENT DYNAMIQUE

Pour les projets qui ont besoin de fonctions serverless ou d'un build (PWA, fetch d'API), Vercel offre un déploiement en un push Git, gratuit pour les usages personnels, sans carte bancaire requise. Le tier gratuit suffit largement à mes volumes.

  • Build automatique depuis GitHub
  • HTTPS par défaut, CDN mondial
  • Aucun lock-in : mes sources restent sur Git
Supabase BASE DE DONNÉES

Quand un projet a besoin d'écrire des données (signalements Vacuum, stockage minimal), Supabase fournit une base PostgreSQL open-source avec auth et API REST clés en main. Le tier gratuit couvre largement les usages communautaires.

  • PostgreSQL standard, exportable
  • Open-source, auto-hébergeable si besoin
  • Row Level Security pour limiter l'accès
GitHub Pages + Pi HÉBERGEMENT STATIQUE

Pour tout ce qui est statique (la majorité), GitHub Pages suffit : zéro coût, zéro config, version en clair. Pour le reste — captures, cron jobs, automatisations — un Raspberry Pi à la maison fait le travail 24/7 pour quelques euros d'électricité.

  • GitHub Pages : sites statiques, déploiement Git
  • Raspberry Pi : automation, π.stream, scripts Python
  • Aucune dépendance à un cloud propriétaire
Pourquoi le gratuit ? PRINCIPE

Le gratuit n'est pas un compromis — c'est un choix politique. Tant qu'un outil reste gratuit, il reste accessible à quiconque veut bâtir, sans barrière financière. Je m'astreins donc à concevoir des projets qui tiennent sur des tiers gratuits : ça force la frugalité, l'efficacité, et garantit que mes outils restent reproductibles par n'importe qui — étudiant, autodidacte, association — sans demander un budget. Quand un service devient payant, je migre. Le code, lui, reste libre.
